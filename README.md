# publisher-data-catalog

Contains a copy of the jsonnet configurations and supporting files for hosting OpenET datasets in the OpenET Publisher Data Catalog in Earth Engine.

https://developers.google.com/earth-engine/datasets/publisher/openet

Users are encouraged to identify and suggest changes to the collection catalog descriptions using the standard github tools (issues, branches, pull requests, etc.).  These changes will be collected by the OpenET team into a single pull request against the main earthengine-catalog repository to minimize the number of changes that are being made.
